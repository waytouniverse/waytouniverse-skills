# GPT-Image-2 图像生成技能

通过 APIMart 平台调用 OpenAI gpt-image-2 模型生成图片。

## 使用场景

- 文生图：根据文字描述生成图片
- 图生图：基于参考图 + 文字描述生成新图片
- 任何需要 AI 绘画/图片生成的场景

## 配置 API Key

本技能通过 APIMart 平台调用生图模型，需要 API Key。如果运行时提示「API Key 为空」或鉴权失败，二选一配置：

1. **环境变量（推荐）**：在 `~/.zshrc` 加一行 `export APIMART_API_KEY=你的key`，然后执行 `source ~/.zshrc`。
2. **直接改脚本**：编辑 `scripts/generate.py`，把 `API_KEY` 变量填成你的 key。

Key 从 APIMart 平台（https://apimart.ai）的 API 管理页获取。

## 如何生成图片

运行生图脚本，传入提示词和可选参数：

```bash
python3 {{SKILL_PATH}}/scripts/generate.py "提示词" [尺寸] [分辨率] [输出目录] [参考图1] [参考图2] ...
```

### 参数说明

| 参数 | 必填 | 说明 |
|------|------|------|
| 提示词 | 是 | 图片的文字描述，支持中英文 |
| 尺寸 | 否 | 图片比例，默认 `1:1` |
| 分辨率 | 否 | 输出分辨率，默认 `1k` |
| 输出目录 | 否 | 图片保存路径，默认当前目录 |
| 参考图 | 否 | 参考图片路径或 URL，最多 16 张 |

### 可用尺寸

`1:1` `16:9` `9:16` `4:3` `3:4` `3:2` `2:3` `21:9` `9:21` `1:3` `3:1` `4:5` `5:4`

### 可用分辨率

- `1k` — 最便宜，约 $0.006/张
- `2k` — 中等，约 $0.05/张
- `4k` — 最高清，价格最高

## 示例

```bash
# 最简文生图
python3 {{SKILL_PATH}}/scripts/generate.py "一只可爱的橘猫坐在窗台上看夕阳，水彩画风格"

# 指定比例和分辨率
python3 {{SKILL_PATH}}/scripts/generate.py "赛博朋克城市夜景" 16:9 2k

# 指定输出目录
python3 {{SKILL_PATH}}/scripts/generate.py "水墨山水画" 1:1 1k ./output

# 图生图（带参考图）
python3 {{SKILL_PATH}}/scripts/generate.py "把这张猫的图片变成油画风格" 1:1 1k . ./cat.jpg
```

## 注意事项

- 图片生成是异步的，通常需要 30-60 秒
- 图片 URL 有时效性（约 24 小时），脚本会自动下载到本地
- 提示词会经过平台安全审核，违规内容会返回错误
- 费用按分辨率档位计费，从 APIMart 账户余额扣除
- **智能风格推断**：如果提示词中未包含风格/画风相关描述（如"水彩"、"油画"、"赛博朋克"等），会自动调用 GPT-5.5 推断最适合的风格并补充到提示词中，提升生图质量；若提示词已包含风格描述，则直接使用原始提示词

## 重要：不要读取生成的图片文件

生成图片后，**绝对不要使用 Read 工具查看生成的图片文件**。只报告文件路径即可。读取图片文件会将图片内容加载到对话上下文中，导致后续对话报错：`Model do not support image input`。
