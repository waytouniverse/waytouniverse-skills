# 联网搜索技能

通过火山引擎豆包 AI Search API 实现联网搜索，获取实时互联网信息。

## 使用场景

当用户的问题需要访问互联网才能回答时，使用此技能。典型场景：

- 最新新闻和热点事件
- 实时天气、股价、汇率
- 近期发布的文章或产品信息
- 任何带有"最新"、"最近"、"今天"、"现在"等时间限定词的问题
- 用户明确要求"搜索"、"查一下"、"搜一下"

## 如何搜索

运行搜索脚本，将用户的查询作为参数：

```bash
python3 {{SKILL_PATH}}/scripts/search.py "用户的搜索查询"
```

可选：自定义搜索角色描述以获得更精准的结果：

```bash
python3 {{SKILL_PATH}}/scripts/search.py "用户的搜索查询" "你是一个金融领域专家，专业解答投资理财问题"
```

## 输出格式

脚本会输出两部分内容：

1. **搜索来源** — 列出参考的网页标题、链接和来源网站
2. **回答文本** — 基于搜索结果生成的结构化回答

## 使用建议

- 如果用户的问题比较宽泛，可以提炼出更具体的搜索关键词
- 对于复杂问题，可以拆分为多次搜索，分别查询不同方面
- 搜索结果可能包含中文互联网的内容，这与用户位置（杭州）相关
- 如果搜索结果不够理想，可以调整角色描述（第二个参数）来引导搜索方向
